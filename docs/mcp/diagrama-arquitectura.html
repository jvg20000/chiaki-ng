chiaki-ng MCP Architecture

Model Context Protocol integration — AI-controlled PlayStation Remote Play

chiaki-ng McpServer (C++)

  • • ~1,633 LOC (header + impl)
  • • QWebSocketServer on configurable port
  • • State machine: Idle → Connected → Streaming
  • • 15 commands via JSON-RPC over WebSocket
  • • Screenshots: FFmpeg decoder → JPEG → base64
  • • Auth: tokenless on localhost, token on 0.0.0.0

chiaki-mcp (TypeScript)

  • • Node.js ≥ 20, pure JavaScript deps
  • • @modelcontextprotocol/sdk v1.25+
  • • Zod validation for all tool parameters
  • • Auto-reconnect with exponential backoff
  • • State validation before each command
  • • Screenshots → MCP ImageContent natively

Security & Config

  • • QSettings-backed: mcp_enabled, port, expose, token
  • • UI tab in SettingsDialog with Switch/SpinBox
  • • Token auto-generated (128 chars hex) on expose
  • • Hot reload on any setting change
  • • SSH tunneling preferred over expose=true
  • • Registered hosts stored in QSettings (pair flow)
